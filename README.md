# HTML-CSS

Repositório dedicado aos exercícios e desafios desenvolvidos durante o curso de HTML5 e CSS3 do **Curso em Vídeo**, ministrado por Gustavo Guanabara.

## 🚀 Projetos

### 🤖 Projeto Android

Página sobre a história do mascote do Android, desenvolvida com HTML5 e CSS3.

**Conceitos praticados:** HTML semântico, estilização CSS, fontes personalizadas e responsividade.

🌐 [Acessar Projeto Android](https://felipemnv.github.io/HTML-CSS/desafios/desafio001/)

### 📜 Projeto Cordel Moderno

Página inspirada no poema *Cordel Moderno*, de Milton Duarte.

**Conceitos praticados:** imagens de fundo, efeito paralaxe, tipografia, espaçamentos e seletores CSS.

🌐 [Acessar Projeto Cordel](https://felipemnv.github.io/HTML-CSS/desafios/desafio002/)

### 🔐 Projeto Login

Interface de login responsiva, desenvolvida com HTML5 e CSS3, com campos de e-mail e senha e adaptação a diferentes tamanhos de tela.

**Conceitos praticados:** formulários HTML, estilização de inputs, pseudo-classes, Media Queries, responsividade, posicionamento de elementos e transições CSS.
